# Student Expense Tracker

A simple web application to manage and track daily expenses for students.

## Features
- Add daily expenses
- Select expense categories
- Calculate total expenses automatically
- View expense history
- Delete expenses
- Save expenses using browser Local Storage

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open `index.html` in your web browser.
3. Start adding your expenses!

## Project Purpose
This project was built to practice HTML, CSS, JavaScript, DOM manipulation, and browser Local Storage.
